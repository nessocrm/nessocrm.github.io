When it starts

The cadences are four intervals: off, 5 minutes, 15, 60. Plus a fixed time, for example 02:10. An integration on pause is skipped by the scheduler and by the webhook. Run now is not.

The fifteen minutes are proved with a fake clock: one second before, it does not start; at the deadline it starts once, and it does not start again in the same minute. It is not a quarter of an hour observed on the container.

Two runs, not only one

Two different integrations can run together. The same one does not start twice: the second is told a run is already in progress. If it is already in progress, the scheduler skips it and does not write an error every thirty seconds.

After an error the clock updates and the full interval is waited. Only with retry_failed on does the clock stay put, and the run can come back sooner.

What the home screen shows

The aligned-accounts percentage counts inbound integrations toward Account. If today's run fails, the percentage is not shown and yesterday's time is not passed off as today.

A file expected within an hour, if that hour passes without a successful run, turns the border red. A file already in the processed folder is not read again. A failed-run notice lights once, with the integration name.
