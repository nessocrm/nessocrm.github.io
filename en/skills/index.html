The owner

By default the source wins, even if the cell arrives empty. Clearing applies only to the source fields. If the owner is Espo, the different value goes into a queue to look at and the field on Espo stays.

On create, the Espo-owned field is written too: the record does not exist yet, and there is no note to protect. From the next run, the owner counts.

The key and the duplicate

Identity is one convention: integration id, a colon, external value. Two integrations on the same sheet do not mix, because the key contains the integration.

If Espo refuses because a similar record already exists with another key, the row is rejected. The integration can be told to adopt that record. It is not the default.

Before Espo

An unreadable date does not invent a day. A list must have at least one value, if the new field is a list. An Italian phone is put into international form. An Espo error, if it names a field, reports that name.

A required column is missing: the file is not moved and the reject is a single one. A cell is missing: the row is rejected and the others continue, if the column is there.
