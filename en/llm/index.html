What it always does

Propose the mapping reads the column names, in the language of the page, and proposes the Espo field, including the VAT number if the sheet has a fiscal field. An unrecognized column stays empty, to be filled by hand.

Synonyms are a list per language. They do not go on the network. They do not save the integration. A person reviews, then saves.

What it does only if you say so

Fill the empty columns calls a model only if the address is set. It fills columns that are still empty, among the fields the sheet knows. It does not touch a column already mapped. It does not save.

The call sends the column names, at most three short cells, and the field name. It does not send the connection password. The model address does not enter the configuration export.

What it is not

It is not an assistant that creates sheets, it does not choose the channel, it does not turn write-back on. If the address is missing, the button says so and the synonym proposal remains.

A run journal and the scheduler stay in the language of the run. The model does not rewrite them.
