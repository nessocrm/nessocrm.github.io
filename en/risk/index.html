Before the write

Preview shows what would be born and what would change, without calling the write. A VAT number already present is seen first. Undo goes back on what the run wrote.

Read mode and the global switch stop writes. A run in read mode reads, compares, and does not send the POST.

Passwords and secrets

Without the NESSO_SECRET_KEY variable the connection password stays cleartext in the SQLite volume. The trial does not set the variable. With the variable, a new save is sealed. An old cleartext row still opens.

Removing the variable after sealing means that connection does not open until the password is typed again. Secrets do not enter the public connection page and do not enter the export.

Things that stay off

The retry queue is off. When on, it queues again only an inbound row that has an external id, not in the same run, and it does not requeue HTTP outbound: that already has its own attempts.

The portal filter is off. It does not create portal users and it does not change roles. When on, outbound skips records of other teams. A missing key still stops the pull.

Mail stays in Espo. The Advanced Pack is not rewritten and is not in the repository. No SQL query on Espo tables. Production dumps are not imported.
