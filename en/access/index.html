The repository

The code is at github.com/nessocrm/nessocrm. There is no installer and there is no waitlist. Whoever wants to try clones the repository and reads the manual in the docs folder.

This page does not ask for an email address. There is no form. The contact is the repository.

What comes up

Docker Compose starts the database, an empty Espo, and the engine. The trial Espo stays empty: production dumps are not imported and attachments are not copied.

Writes toward Espo go through the HTTP API. No query on Espo tables. The Advanced Pack, if someone has it locally, is not in the repository and is not published.

What stays off

Write-back, retry queue, portal filter, seal: off. The NESSO_SECRET_KEY variable is not set, so a password saved in the trial stays cleartext on the volume. It is written in the manual, it is not a surprise.

Mail is not configured from here. A run journal stays in the language of the run.
