The source wins

The default is the source. If tonight's file brings an empty city, the city on Espo becomes empty. It is the behavior expected of a load: the file is the truth of those fields.

Clearing is not a side effect on the whole sheet. It applies to the fields the source owns. An unmapped field is not touched.

Espo wins

A field can be said to belong to Espo. A note written by a person, a value corrected by hand, stay. If the file brings a different value, that value goes into a queue to look at. The field on Espo does not change.

On create the field is written anyway: there is not yet a note to protect. From the next run the owner counts.

Who wrote last

The badge on the record says who wrote last. It is there for whoever needs to see whether the row is still the file's or whether someone in Espo corrected it.

It is not a legal history. It is the mark, on the record, of the last run that touched it.
