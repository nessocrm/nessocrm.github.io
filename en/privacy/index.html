This site

The pages are static files on GitHub Pages. There is no account, no form, no list. The only memory in the browser is the theme and the closing of the notice, described on the Cookies page.

The typeface, the style, and the icons come from third-party CDNs. This site does not add an analytics tag. The host logs belong to GitHub.

No company, VAT number, or postal address is given: they are not project data published here. The public reference is the repository github.com/nessocrm/nessocrm.

The program, if you start it

The engine does not run on these pages. If you start it from the repository, it keeps connections, integrations, the journal, the hash, and the cursor in a SQLite file on the volume you choose. The sheets sit in Espo, not here.

Without NESSO_SECRET_KEY the connection password stays cleartext in that volume. With the variable, a new save is sealed. The public trial does not set the variable. Secrets do not enter the public view of the connection.

Production dumps are not to be imported into the trial Espo. This page does not receive them and does not want them.
