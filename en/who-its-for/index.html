Whoever keeps the number

On the home screen there is one number that counts: accounts aligned today, and the balance if there is an amount. It counts only if today's run toward Account succeeded. It is a check. It does not write.

If the run fails, the number is not shown with yesterday's time. An expected file that does not arrive turns the border on.

Whoever has the note

The salesperson writes on the record. The note field has Espo as owner, so the night file does not clear it. The badge says who wrote last.

If the file brings a different value, that value goes into a queue to look at. It does not overwrite the note.

Whoever checks

Administration opens the preview. They see a VAT number already present before the run writes. They can undo what the run wrote.

The first close of disappeared records asks for confirmation. A truncated file does not close the list on its own.

Whoever installs

Four steps: connection, sheet, mapping, run. The recipe is a starting point to review, not a certified connector. The switch-on plan says what stays off.

The handover page does not contain passwords. Without NESSO_SECRET_KEY the volume keeps them in cleartext: it has to be said to whoever receives the trial, not hidden.
