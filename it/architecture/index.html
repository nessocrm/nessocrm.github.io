Accesso a EspoCRM tramite API

Le letture e le scritture su EspoCRM utilizzano le sue API HTTP. Anche la creazione di schede e campi passa dalle API: Nesso non esegue query SQL sul database del CRM.

Collegamenti e integrazioni separati

Il collegamento definisce come comunicare con il sistema esterno. L’integrazione definisce quali dati trasferire, dove scriverli e con quale frequenza.

Uno stesso collegamento può essere utilizzato da più integrazioni. Puoi quindi gestire flussi diversi senza duplicare ogni volta la configurazione del canale.

Una memoria operativa del trasferimento

Nesso conserva in SQLite configurazioni, identificativi, impronte dei dati, avanzamento degli invii e registro delle attività. Queste informazioni permettono di riconoscere i record già elaborati e consultare gli esiti.

Permessi e configurazione dell’ambiente

Le elaborazioni usano un utente EspoCRM dedicato, con un ruolo legato alle integrazioni attive. La creazione di schede e campi utilizza invece le credenziali amministrative di configurazione.

Il repository include un ambiente Docker Compose per la valutazione locale. Requisiti, protezione delle credenziali e impostazioni operative sono descritti nel manuale.
