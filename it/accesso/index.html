Prepara l’ambiente di prova

Per iniziare servono Git e Docker con Compose. Scarica il repository e segui le istruzioni di avvio nel README e nel manuale. L’ambiente comprende Nesso, EspoCRM e il database.

Apri il repository su GitHub

Esplora un caso aziendale dimostrativo

Il primo avvio installa un’istanza EspoCRM dedicata e carica i dati fittizi del Gruppo Meridia. Puoi seguire nel manuale i flussi di clienti, contatti, documenti e attività.

La prova utilizza dati dimostrativi: non richiede di importare database o allegati di produzione.

Verifica i requisiti prima dell’adozione

Controlla che i canali e i formati supportati corrispondano ai tuoi sistemi. Rivedi abbinamenti, regole dei campi, permessi e risultati delle anteprime.

La demo non configura NESSO_SECRET_KEY: le credenziali salvate nel volume locale restano in chiaro. Il manuale descrive come abilitare la protezione. Scrittura di ritorno, nuovi tentativi automatici e filtri opzionali richiedono una configurazione esplicita.

Le estensioni commerciali di EspoCRM, come l’Advanced Pack, non sono distribuite nel repository. Verifica nel manuale i requisiti dello scenario che vuoi provare.
