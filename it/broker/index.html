File CSV ed Excel, locali o remoti

Importa file da una cartella locale o da un server SFTP o FTPS. Nesso legge le intestazioni e applica gli abbinamenti configurati. I file elaborati vengono archiviati; se manca una colonna obbligatoria restano in attesa di correzione.

I collegamenti SFTP e FTPS supportano anche la consegna in uscita di file CSV.

Database aziendali

Leggi i dati da MySQL, MariaDB, PostgreSQL, SQL Server e Oracle tramite query SELECT. La scrittura di ritorno è un’opzione separata, da attivare per l’integrazione e limitare alle colonne indicate.

TLS e tunnel SSH sono opzioni del collegamento da configurare in base al proprio ambiente.

Webhook e destinazioni HTTP

Ricevi dati inviati da un sito o da un’applicazione tramite un indirizzo protetto da token. Puoi configurare anche la verifica della firma del messaggio.

Invia i dati di EspoCRM a una destinazione HTTP con le modalità di autenticazione supportate, tra cui Bearer, credenziali utente e OAuth con credenziali client.

Documenti associati al CRM

Importa documenti nella cartella e nel team di EspoCRM indicati. Il canale PDF può associare il file a un’azienda quando il nome contiene la sua chiave identificativa completa.

La compatibilità va verificata sul formato dei dati e sulle interfacce disponibili nel sistema esterno. I canali non rappresentano connettori certificati per specifici gestionali.
