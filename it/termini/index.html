Contenuti del sito

Le pagine presentano funzionalità e limiti del progetto. Per i dettagli operativi consulta il manuale nella cartella docs del repository, aggiornato insieme al prodotto.

Uso del software

Per le condizioni di utilizzo e distribuzione del codice, consulta i file presenti nel repository. La disponibilità del codice su GitHub non sostituisce la verifica delle condizioni applicabili.

La compatibilità con un sistema aziendale richiede una valutazione dei canali, dei formati e delle regole da configurare. La demo locale consente di iniziare questa verifica con dati fittizi.

Componenti esterni

Le estensioni commerciali di EspoCRM, incluso l’Advanced Pack, non sono distribuite nel repository Nesso. Il loro utilizzo dipende dalle condizioni del relativo fornitore.
