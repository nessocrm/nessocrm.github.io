Vince la sorgente

Il default è la sorgente. Se il file di stanotte porta la città vuota, la città su Espo diventa vuota. È il comportamento che ci si aspetta da un caricamento: il file è la verità di quei campi.

Lo svuotamento non è un effetto collaterale su tutta la scheda. Vale sui campi che la sorgente possiede. Un campo non abbinato non viene toccato.

Vince Espo

Si può dire che un campo è di Espo. Una nota scritta da una persona, un valore corretto a mano, restano. Se il file porta un valore diverso, quel valore finisce in coda da guardare. Il campo su Espo non cambia.

In creazione il campo si scrive lo stesso: non esiste ancora una nota da proteggere. Dal giro successivo il padrone conta.

Chi ha scritto per ultimo

Il badge sul record dice chi ha scritto per ultimo. Serve a chi deve capire se la riga è ancora quella del file o se qualcuno in Espo l'ha corretta.

Non è una cronologia legale. È il segno, sul record, dell'ultimo giro che l'ha toccato.
