# Nesso — sito

Sito di Nesso, lo strumento di integrazione che collega EspoCRM ai sistemi aziendali. Jekyll, senza Actions. Italiano in `/it/`, inglese in `/en/`.

Il manuale del prodotto sta nel repository [nessocrm/nessocrm](https://github.com/nessocrm/nessocrm), cartella `docs/`. Questo sito non lo ricompila.

## Anteprima locale

```bash
bundle install
bundle exec jekyll serve
```

Apri `http://127.0.0.1:4000/it/`.

## Linea editoriale italiana

Il messaggio principale è: «Collega EspoCRM ai tuoi sistemi. Tieni i dati sotto controllo.» Presentare prima il problema e il beneficio, poi il funzionamento e i requisiti.

Usare termini espliciti: esecuzione o elaborazione, priorità del campo, abbinamento, modello di configurazione, protezione delle credenziali. Evitare metafore come «giro», «padrone», «chi vince la cella», «ricetta» e «sigillo» nei testi di presentazione. Quando si cita un comando dell’applicazione, conservarne il nome reale.

La demo locale installa EspoCRM e carica i dati fittizi del Gruppo Meridia. Le opzioni da attivare e i limiti della prima versione vanno indicati nelle pagine pertinenti. Non promettere compatibilità universale, certificazioni o risultati non verificati. Il sito non raccoglie iscrizioni: l’invito principale è «Prova Nesso», con istruzioni per la demo locale.

La revisione del copy riguarda la versione italiana e i relativi testi condivisi. I contenuti inglesi restano nella versione precedente.
